Windows 上的主动防御杀软

X-Safe 把病毒查杀、行为判断、云端比对和系统关键位置的监控，都收进一个中文界面。 发现可疑先问你，删不删由你定，不懂安全也能上手。

怎么查杀

三套一起上，结果互相印证

特征、AI 行为、云端三套各自打分，最后合在一起判断危险程度，比单靠一种更稳。

特征引擎

认已知的坏东西

哈希签名加规则匹配，已知病毒家族基本都能认出来。

AI 自学习引擎

看行为打分

看文件的行为习惯打分，还会跟着你的反馈越用越准。

云端查杀（可选）

360 云 + VirusTotal

联网时再对一遍群体判定；断网可以关掉，纯本地也能跑。

盯着哪

系统关键位置，一直盯着

不只是扫一遍，出问题当场拦：解压、下载、注册表、引导区、进程动作都在监控里。

文件系统监控

watchdog 实时监听，PollingObserver 对系统目录兜底，文件创建/修改/移动即刻扫描。

注册表监控

盯紧 Run / IFEO / Winlogon Shell / AppInit_DLLs / Userinit 等关键自启与注入项。

引导区保护

对 MBR / VBR 建立哈希快照，发现篡改立即告警，守住系统最底层。

进程行为监控

识别异常父子进程、DLL 注入与批量加密写文件，勒索行为实时拦截。

系统敏感文件

对 hosts、计划任务、启动项、卷影副本、SAM 等关键点持续巡检。

自保护白名单

程序自身与 _internal 目录默认豁免，避免 PyInstaller 依赖被误报导致无法运行。

其它

自检、找回文件、弹窗提示

防护自检、勒索恢复、威胁弹窗这些常用的，也都做了。

系统自检

隔离区完整性 + 引导区 + 注册表基线一键巡检，快速确认防护体系健康度。

勒索恢复

WannaCry / EternalBlue 痕迹检测 + 卷影副本恢复，针对性挽回被加密的文件。

ThreatToast 弹窗

屏幕右下方累积摘要弹窗——狂涌 500+ 威胁也只弹 1 个，单条带删除/隔离/自检/忽略。

浅 / 深双主题

一键切换，通过 os.execv 重启进程换肤，长时间守屏也护眼。

数据本地化

所有用户数据落到 %TEMP%\XSafe\，跨会话存活，不受公司/家庭策略重定向影响。

不自动处置

检测到威胁先弹窗，由你决定删除/隔离/自检/忽略，要不要处置、怎么处置，都由你决定。

上手

三种方式，挑顺手的

普通用户直接下 exe；会写代码就从源码跑，或者自己打包。

1

下载预编译 exe

# 从 Releases 下载 XSafe_v*.zip # 解压后双击 XSafe.exe 即可
数据目录自动落在 %TEMP%\XSafe\
2

从源码运行

git clone <repo> cd X-Safe python -m venv .venv pip install -r requirements.txt python main.py
3

打包成 exe

pip install pyinstaller # 先清缓存，避免旧代码 rm -rf build/ dist/ pyinstaller main.spec --noconfirm --clean
